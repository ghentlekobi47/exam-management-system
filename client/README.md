# CampusIQ website

The React front end of CampusIQ. See the [main README](../README.md) for features, setup and scripts, and [DEPLOYMENT.md](../DEPLOYMENT.md) for hosting on Vercel.

```bash
npm run dev      # http://localhost:5173 (needs the API running; see the main README)
npm run build    # production build in dist/
npm run lint
```

Settings: copy `.env.example` to `.env` and set `VITE_API_URL` to the API's address.
